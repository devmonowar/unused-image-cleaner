# Unused Image Cleaner — help

This folder is written for people **using** the plugin. If you're looking for how it's built
internally, that's not here — see the plugin's `readme.txt` for the short version, or get in touch
with the maintainer for anything deeper.

- **[Getting Started](getting-started.md)** — install it, run your first scan, see what comes back
- **[Understanding Your Results](understanding-your-results.md)** — what Confidence, Risk, and each
  recommendation actually mean, and why a high-confidence image can still say "Review"
- **[Staying Safe](staying-safe.md)** — what the plugin will never do, how Trash and Restore work,
  and why some images can't be selected for deletion at all
- **[FAQ](faq.md)** — quick answers to the questions people ask most

For installation requirements, the full changelog, and the short-form FAQ, see the plugin's
`readme.txt` — that's also what shows up on the plugin's WordPress.org-style listing page.

## Extending the plugin

If you're a developer looking to hook into a scan or add your own scanner, see
**[Developer Hooks](hooks.md)** instead — everything else in this folder is written for people
using the plugin as-is.
